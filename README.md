# SKYE Demo de Gestão Comercial

Demonstração comercial estática, interativa e reutilizável, construída com dados inteiramente fictícios.

## Acessar a demonstração

https://macimiano.github.io/skye-demo-gestao-comercial/

## Recursos demonstrados

- painel de pedidos e indicadores;
- criação e acompanhamento de pedidos;
- venda por tamanho, peso ou valor da balança;
- pagamentos simples ou divididos;
- clientes, pesquisas, cadastros e edições;
- cardápio, estoque e fichas técnicas;
- contas a pagar e receber;
- relatório de vendas;
- mensagens simuladas;
- usuários e configurações;
- restauração dos dados fictícios.

## Reutilizar o modelo

Edite `config.js` para alterar:

- nome fictício da operação;
- segmento exibido no menu;
- cidade e endereço fictícios;
- chave de armazenamento local;
- cores principais.

Use uma `storageKey` diferente para cada demonstração publicada. Nunca inclua dados reais ou sigilosos, pois os arquivos deste repositório são públicos.

## Funcionamento

A aplicação usa somente HTML, CSS e JavaScript. Os registros são simulados e permanecem no armazenamento local do navegador. Não existem backend, banco de dados, login real ou integrações externas ativas.

Desenvolvido por **SKYE Gestão e Inovação**.
